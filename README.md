# Ghummoo - Local Guide Booking Platform

## 📌 Project Overview
**Ghummoo** is a full-stack web application that enables travelers
to discover and book **certified local guides**.  
The platform ensures **trust, quality, and transparency** through a structured
certification and verification system managed by administrators.

This project is developed as part of the **SESD (Software Engineering & System Design)**
course and will be evaluated across the semester.

---

## 🎯 Objectives
- Provide travelers with access to verified local guides
- Enable guides to apply for certification and manage bookings
- Allow administrators to verify, certify, and monitor platform activity
- Demonstrate strong backend-focused system design and OOP principles

---

## 👥 Actors
- **Traveler (User)** – Searches guides, books services, submits reviews
- **Guide** – Applies for certification, manages availability, accepts bookings
- **Admin** – Verifies guides, approves certifications, manages users

---

## ✨ Core Features
- Role-based authentication and authorization
- Guide certification and verification workflow
- End-to-end booking management
- Review and rating system
- Admin moderation and monitoring
