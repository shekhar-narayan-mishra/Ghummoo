# Local Guide Booking Platform

## Problem Statement
Travelers often struggle to find trusted and verified local guides.
There is no standardized system to certify guides and ensure quality service.

## Objective
To build a full-stack platform where travelers can book certified local guides,
guides can manage availability, and admins can verify and certify guides.

## Scope
- User authentication and role-based access
- Guide certification and verification
- Booking and cancellation workflow
- Review and rating system
- Admin moderation

## Key Features
- Traveler booking system
- Guide certification test & approval
- Availability management
- Reviews and ratings
- Admin dashboard

## Actors
- Traveler (User)
- Guide
- Admin

## Tech Stack (Tentative)
- Backend: Node.js / Java (Spring Boot)
- Frontend: React
- Database: PostgreSQL / MySQL
- ORM: Sequelize / Hibernate
